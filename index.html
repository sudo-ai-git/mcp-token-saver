The problem is the resend, not the model

Agent frameworks append every tool result to a growing context. When a tool returns a large payload (a Kubernetes manifest, a log tail, a GitHub API response), that same payload is re-sent to the model on every subsequent turn — whether or not it changed. The token hammer gets heavier the longer the loop runs, and the bill climbs with it.
